# افیلیت پرو — سیستم بازاریابی چندسطحی (PWA + Django)

## نصب و راه‌اندازی

```bash
# 1. استخراج فایل
unzip affiliate_pwa_project.zip
cd affiliate_pwa   # یا همان پوشه‌ای که فایل‌ها داخلش هستند

# 2. ساخت محیط مجازی (پیشنهادی)
python3 -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate

# 3. نصب وابستگی‌ها
pip install django djangorestframework django-cors-headers pillow python-decouple django-crispy-forms crispy-bootstrap5

# 4. مایگریشن
python manage.py migrate

# 5. ساخت ادمین
python manage.py createsuperuser

# 6. اجرای سرور
python manage.py runserver
```

سپس به آدرس http://127.0.0.1:8000 بروید.

## حساب‌های پیش‌فرض (اگر از دیتابیس آماده استفاده کنید)

- ادمین: `admin` / `admin123`
- کاربر دمو: `demo` / `demo123`

## ویژگی‌های جدید پنل مدیریت کاربران

### وضعیت بررسی (رنگی)
- 🔴 **بررسی‌نشده (pending)** — پیش‌فرض بعد از ثبت از لینک معرف
- 🟡 **بررسی‌شده (reviewed)** — ادمین بررسی کرده
- 🟢 **خریده (purchased)** — خرید انجام شده + تاریخ خرید قابل ثبت

### امکانات ادمین
- فیلتر سریع بر اساس وضعیت (رنگ‌ها)
- تغییر وضعیت دسته‌جمعی با Actions
- ثبت تاریخ خرید
- ثبت صنف کاری
- تبدیل هر کاربر به ادمین (is_staff) با یک کلیک
- لیست قابل ویرایش (status، تاریخ خرید، صنف)
- نمایش بج‌های رنگی و حرفه‌ای

### ثبت بسته (محدود)
- دکمه صفحه اصلی و منو: **ثبت بسته** (دیگر «ثبت‌نام رایگان» نیست)
- کاربران عمومی **نمی‌توانند** خودشان حساب کامل بسازند
- از طریق لینک معرف فقط **نام + شماره موبایل + صنف کاری** ثبت می‌شود
- اگر لینک معرف نداشته باشد، به‌صورت خودکار به کد معرف **۱** وصل می‌شود (باید یک کاربر با `referral_code=1` در سیستم وجود داشته باشد)
- حساب کامل و رمز عبور فقط توسط ادمین از پنل مدیریت ساخته/فعال می‌شود

## ویژگی‌های کلی

- سیستم سه‌سطحی: برنزی (۵٪) → نقره‌ای (۱۰٪) → طلایی (۱۲٪)
- کد و لینک معرف اختصاصی
- کیف پول و درخواست برداشت (فقط طلایی)
- خرید بسته با پول یا امتیاز
- درخواست تمدید پشتیبانی با امتیاز
- پنل ادمین کامل و ریسپانسیو
- رابط کاربری مدرن و RTL (PWA)

## ساختار پوشه‌ها

- `accounts/` — کاربران و پروفایل
- `products/` — بسته‌ها
- `orders/` — سفارشات و کمیسیون
- `wallet/` — کیف پول و برداشت
- `support/` — تمدید پشتیبانی
- `referrals/` — ردیابی لینک معرف
- `templates/` — قالب‌های HTML
- `static/` — فایل‌های استاتیک و PWA

## نکات

- در حالت DEBUG=True هست. قبل از استقرار روی سرور، SECRET_KEY را عوض کنید و DEBUG را False کنید.
- برای اتصال درگاه پرداخت (زرین‌پال و ...) باید در `products/views.py` بخش `buy_package` را گسترش دهید.

## وضعیت درخواست برداشت
- خوانده‌نشده (پیش‌فرض)
- خوانده‌شده
- تأیید شده (کسر از کیف پول)
- رد شده
- پرداخت شده

از پنل ادمین → درخواست‌های برداشت می‌توانید با Actions وضعیت را تغییر دهید.
